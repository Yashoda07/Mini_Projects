## Basic Calculator (Work in Progress)

This project is a simple calculator web application built using **HTML, CSS, and JavaScript**. It currently supports basic arithmetic operations and serves as a foundational project to practice **DOM manipulation** and **event handling**.

The application is still under development, with additional features and user interface improvements planned for future iterations.

---

### Current Status

- Core structure and basic functionality implemented  
- Minimal user interface (UI) requiring enhancements  
- Additional JavaScript features in progress  

---

### Planned Improvements

- Enhance UI/UX design for a better user experience  
- Add keyboard input support  
- Improve error handling and input validation  
- Implement advanced mathematical operations
